# 分流标签（Triage Labels）

技能按照五种规范的分流角色来表述。本文件将这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                                     |
| -------------------------- | ------------------ | ---------------------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估此 issue                   |
| `needs-info`               | `needs-info`       | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可供 AFK 智能体处理            |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                             |
| `wontfix`                  | `wontfix`          | 将不予处理                               |

当技能提及某个角色时（例如 "apply the AFK-ready triage label"），请使用本表中对应的标签字符串。

编辑右侧列以匹配你实际使用的词汇。
